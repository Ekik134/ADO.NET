## Что изучалось
На занятии были рассмотрены основы работы с ADO.NET и Dapper в ASP.NET Core MVC приложениях.

## Структура папки

| Элемент | Краткое описание |
| :--- | :--- |
| **SCRINSHOTS** | Каталог со скриншотами практики. |
| **README.md** | Файл с описанием темы занятия и сутью задания. |
| **практика.md** | Файл с выполненной практикой. |
| **pharmacy.rar** | Заархивированная папка с исходным кодом проекта. |

## Суть задания
1. GET /meds?q= — Dapper с QueryMultiple (соединение + пул + параметры);
2. POST /sale — продажа в транзакции: ExecuteScalar + ExecuteNonQuery (команда + параметры + транзакция + async);
3. GET /meds/report — DataSet/DataAdapter/DataTable.

# Что изучалось

В ходе выполнения задания были рассмотрены основы контейнеризации ASP.NET Core приложений с помощью Docker, а также интеграция веб-приложения с базой данных PostgreSQL. ## Суть задания

Разработать и запустить в Docker веб-приложение ShopApp со следующей функциональностью:

1. **Структура проекта** — создать MVC-приложение с папками `Controllers`, `Models`, `Data`, `Views`, а также файлами `docker-compose.yml`, `Dockerfile` и `appsettings.json`. Подключить актуальную версию пакета Npgsql.
2. **Сборка контейнера** — настроить `docker-compose.yml` для совместного запуска веб-приложения и СУБД PostgreSQL. Собрать и запустить контейнеры командой `docker compose up --build`.
3. **Проверка работы БД** — убедиться в успешном подключении приложения к PostgreSQL и корректном создании/чтении данных.
4. **Функционал каталога** — реализовать просмотр списка товаров, добавление нового товара в каталог, просмотр деталей товара, а также функцию «покупки» товара с обновлением статуса (пометка «куплено») в базе данных.
